# Morvarid

A React + TypeScript + Vite application for egg import operations, batch management, sales, expenses, and profit reporting.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Getting started

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — run TypeScript project checks and create a production build
- `npm run preview` — preview the production build locally

## Project status

Initial application scaffold. Business modules, Google authorization, Google Sheets integration, Excel import, and PDF reporting have not been implemented yet.
